# Spendly

Персональное приложение для учёта доходов и расходов. Данные хранятся в PocketBase.

## Возможности

- Учёт стартового капитала, доходов и расходов
- Автоматический расчёт баланса, прибыли и статистики
- Периоды учёта с историей
- Накопления (копилки)
- Графики баланса и расходов по категориям
- Поиск, фильтры и редактирование операций
- Тёмная и светлая тема
- Локализация RU / EN / AZ
- Экспорт и импорт данных в JSON

## Стек

- React + Vite + TypeScript
- PocketBase (авторизация и данные)
- Capacitor (нативная Android-оболочка)
- Recharts (графики)

## Запуск

```bash
npm install
npm run pocketbase:serve
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Структура данных

- **User** — профиль (имя, валюта)
- **Period** — период учёта (название, стартовый капитал, даты)
- **Transaction** — операция (доход/расход, сумма, категория, дата)
- **SavingGoal** — накопления

## Формулы

- Баланс = стартовый капитал + доходы − расходы
- Прибыль = доходы − расходы
